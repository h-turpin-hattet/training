# training

Personal knowledge base: notes and templates I can look up when I am
stuck, organized by topic. Not a showcase, a working tool.

## Structure

| Folder | Content |
|---|---|
| `python/notes/` | Quick references by topic: lists, dictionaries, strings, loops, functions, classes... |
| `python/freecodecamp/` | Exercises from the freeCodeCamp Python course |
| `python/sandbox/` | Drafts and practice exercises |
| `pytest/` | Notes on writing tests, plus a test template |
| `github-actions/` | Notes on workflows, plus a lint + test workflow template |
| `git/notes/` | Git and Git Bash commands I use |

## How to use

Each note is a short file: one section per method, an example, and the
result in a comment. Python notes can be run (`python lists.py`).
Templates are meant to be copied into a new project.
